# Sample TLP reports (fictional students)

Upload all four at once on an **empty** platform (HOD: `hod.cse@acadlytics.dev`) to see the
reports set everything up:

| File | What happens |
|---|---|
| `DSA_FJ-II_A1.xlsx` | Creates semester AY2025-26-EVEN, course 21CSC201J, section A1, 42 students, faculty login `902049@srmist.edu.in`, test FJ-II |
| `DSA_FJ-II_A2.pdf` | Section A2 (from the file name), 40 students, faculty `902050@…` |
| `dsa_marks_new.csv` | No section in its name and new students: **Section needed** → type `B1` |
| `OS_FT2.xlsx` | Course 21CSC202J for the A1 students — section A1 is recognised from the students |

Then **Confirm**. Upload any file again to see it reported as a duplicate; discard a staged file
to see what it set up removed.
