# Sample TLP reports (fictional students)

Fictional data for testing only. Nothing in the application loads these; they are what
`scripts/e2e_live.py` uploads, and you can upload them by hand on a **throwaway** platform
(as the HOD or Administrator) to see reports set everything up. Do not upload them into a
platform that holds real marks.

| File | What happens |
|---|---|
| `DSA_FJ-II_A1.xlsx` | Creates semester AY2025-26-EVEN, course 21CSC201J, section A1, 42 students, faculty account `902049@srmist.edu.in` (set its password in *People*), test FJ-II |
| `DSA_FJ-II_A2.pdf` | Section A2 (from the file name), 40 students, faculty `902050@…` |
| `dsa_marks_new.csv` | No section in its name and new students: **Section needed** → type `B1` |
| `OS_FT2.xlsx` | Course 21CSC202J for the A1 students — section A1 is recognised from the students |

Then **Confirm**. Upload any file again to see it reported as a duplicate; discard a staged file
to see what it set up removed.
