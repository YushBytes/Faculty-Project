# TLP upload demo files

Generated by `python -m app.cli seed-demo` (deterministic; fictional students).

Sign in as the DSA Course Coordinator (`coord.dsa@acadlytics.dev`), open **Import**, and drop every file here at once. Each file is routed to its section by the register numbers it contains and to FJ-III by its test name. Expect:

* eight files **valid** (xlsx, csv and TLP-format pdf)
* `*_wrong-max.*` **error**: the report says the component is out of 20; FJ-III is out of 15
* `*_needs-fix.*` **error**: one mark above the maximum; fix the cell in the preview or exclude the row

Upload any file twice to see it reported as a duplicate.
